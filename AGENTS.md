## Core Coding Principles (Karpathy)

1. **Think Before Coding**: Don't assume. Surface tradeoffs explicitly. Name confusion early.
2. **Simplicity First**: Minimum code that solves the problem. No premature abstractions or speculative features.
3. **Surgical Changes**: Touch only what you must. Don't reformat adjacent code or refactor untouched parts.
4. **Goal-Driven Execution**: Define verifiable criteria (e.g., tests pass) and loop until verified.
